# Father Payment — site institucional (React + Vite)

Desenvolvido por Crystal Code.

## Como rodar

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # gera a pasta dist/
npm run preview  # testa o build
```

## Estrutura

- `src/components/` — uma seção por componente (Header, Hero, About, Solutions, Differentials, Principles, Contact, Faq, FinalCta, Footer)
- `src/hooks/` — `useReveal` (animação de entrada) e `useScrollSpy` (barra de progresso e menu ativo)
- `src/constants.js` — e-mail, WhatsApp e logo
- `src/index.css` — estilos (mesmos do site original)
- `public/logo.png` — logo
